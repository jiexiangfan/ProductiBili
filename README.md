## Install

[Get it on the Chrome Web Store](https://chromewebstore.google.com/detail/kbeeegjjikobknoihlpjmebhcolfmdoj)

## Where is the source code?

ProductiBili is no longer open source. The project received little community contribution while there are many similar clones in the store now.

The extension remains actively developed. GitHub issues are still open for bug reports and feature requests — feel free to use them.

## Features

- Hide or show specific sections of Bilibili — recommendations, comments, sidebar, trending, subscriptions feed, and Danmaku
- Preferences are saved automatically so your setup persists across visits
- Multi-language support built into the popup menu
